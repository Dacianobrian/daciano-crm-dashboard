# Dashboard CRM - Daciano Brian

Dashboard estático para acompanhar métricas do CRM Daciano Brian no ClickUp.

## Métricas

- Leads chamados no dia
- Leads movidos para sondagem
- Leads com simulação feita
- Leads aguardando documentos
- Leads em análise de crédito
- Distribuição por status
- Tabela de leads recentes

## Publicação no GitHub Pages

1. Crie um repositório no GitHub chamado `daciano-crm-dashboard`.
2. Envie os arquivos desta pasta para o repositório.
3. No GitHub, abra `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve.

Depois de alguns minutos, o dashboard ficará disponível em:

```text
https://SEU-USUARIO.github.io/daciano-crm-dashboard/
```

## Observação

Este dashboard usa um snapshot dos dados do ClickUp gerado em 08/05/2026. Para atualização automática, será necessário adicionar um pequeno processo de sincronização com a API do ClickUp.
